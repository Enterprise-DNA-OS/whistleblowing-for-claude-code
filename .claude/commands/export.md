# Export every record to CSV and one JSON snapshot

Run `node scripts/speakup.mjs export [--out=folder] --json`. Tell the operator where the files are and that they hold confidential case records.

Start from the command output, never memory. Use record references in the answer. Never write a discloser's name into the database, a note or a draft.
