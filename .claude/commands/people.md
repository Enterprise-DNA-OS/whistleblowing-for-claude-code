# Case officers, eligible recipients and investigators

Run `node scripts/speakup.mjs people --json`. Point out anyone untrained or trained more than `training_months` ago. Record training with `node scripts/speakup.mjs trained <person> [--date=]`.

Start from the command output, never memory. Use record references in the answer. Never write a discloser's name into the database, a note or a draft.
