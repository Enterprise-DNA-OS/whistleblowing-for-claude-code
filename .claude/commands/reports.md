# Every open case, most serious first

Run `node scripts/speakup.mjs reports --json`. Show reference, entity, category, severity, status, officer, days open, the acknowledgement due date and the next step. Call out anything with no officer or no next step.

Start from the command output, never memory. Use record references in the answer. Never write a discloser's name into the database, a note or a draft.
