# The quarterly report to the board or audit and risk committee

Run `node scripts/speakup.mjs board-report --json`. Write a short covering note: volumes by entity, categories, how many substantiated, how long cases take, and any compliance flags. Numbers and categories only: never a summary, alias, area or contact route. Offer `/draft-board-report`.

Start from the command output, never memory. Use record references in the answer. Never write a discloser's name into the database, a note or a draft.
