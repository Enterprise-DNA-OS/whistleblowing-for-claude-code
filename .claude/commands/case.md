# The whole file for one case

Run `node scripts/speakup.mjs case <report> --json` with the reference or alias the operator gives. Present: what was reported, where it is up to, contact with the discloser, actions, who has been told the identity and on what basis, and retaliation checks. End with what is due next.

Start from the command output, never memory. Use record references in the answer. Never write a discloser's name into the database, a note or a draft.
