# Save the board report as a branded document

Run `node scripts/speakup.mjs draft-board-report --json`, or `npm run docs -- board-report` for one report per entity. Nothing is sent.

Start from the command output, never memory. Use record references in the answer. Never write a discloser's name into the database, a note or a draft.
