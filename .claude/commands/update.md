# Log an update sent to the discloser, or something they sent us

Sent to them: `node scripts/speakup.mjs update <report> --text="..." --json`. Heard from them: `node scripts/speakup.mjs heard <report> --text="..." --json`. Write the summary without names. If the update has not been written yet, use `/draft-update` first.

Start from the command output, never memory. Use record references in the answer. Never write a discloser's name into the database, a note or a draft.
