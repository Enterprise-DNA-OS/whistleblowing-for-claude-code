# Closed cases with findings and whether the discloser was told

Run `node scripts/speakup.mjs closed --json`. Show finding, days to close and whether the outcome was told. Flag any closed case with no outcome told.

Start from the command output, never memory. Use record references in the answer. Never write a discloser's name into the database, a note or a draft.
