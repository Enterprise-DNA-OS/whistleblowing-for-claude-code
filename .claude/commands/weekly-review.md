# The Monday speak-up review, from three commands

Run `node scripts/speakup.mjs weekly-review --json`. It returns attention, open cases and workload. Write it in three parts: what must happen this week to protect disclosers (with owners), where each open case is up to, and who is overloaded. Offer `/draft-weekly-review` to save it.

Start from the command output, never memory. Use record references in the answer. Never write a discloser's name into the database, a note or a draft.
