# Group companies, their policies and their numbers

Run `node scripts/speakup.mjs entities --json`. Show policy review dates and the last 12 months of reports. Record a reviewed policy with `node scripts/speakup.mjs policy <entity> [--date=]`.

Start from the command output, never memory. Use record references in the answer. Never write a discloser's name into the database, a note or a draft.
