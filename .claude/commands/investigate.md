# Move a case into investigation with its next step

Run `node scripts/speakup.mjs investigate <report> --next-step="..." --due=YYYY-MM-DD --json`. The discloser must be acknowledged first unless there is no way to reach them.

Start from the command output, never memory. Use record references in the answer. Never write a discloser's name into the database, a note or a draft.
