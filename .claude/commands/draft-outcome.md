# Draft the outcome message to a discloser

Run `node scripts/speakup.mjs draft-outcome <report> --json`. Edit the outcome line down to what can be shared. Nothing is sent. Once sent, run `node scripts/speakup.mjs told-outcome <report>`.

Start from the command output, never memory. Use record references in the answer. Never write a discloser's name into the database, a note or a draft.
