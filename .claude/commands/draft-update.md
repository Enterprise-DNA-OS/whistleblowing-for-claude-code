# Draft a progress update to a discloser

Run `node scripts/speakup.mjs draft-update <report> --json`. Read the draft and remove anything that could identify a witness, the subject or the discloser. Nothing is sent. Once sent, log it with `/update`.

Start from the command output, never memory. Use record references in the answer. Never write a discloser's name into the database, a note or a draft.
