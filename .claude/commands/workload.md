# Who is carrying which cases

Run `node scripts/speakup.mjs workload --json`. Show open cases, high severity, overdue actions and average days to close for each officer, and name anyone over `max_open_cases`.

Start from the command output, never memory. Use record references in the answer. Never write a discloser's name into the database, a note or a draft.
