# The confidential case file as one document

Run `node scripts/speakup.mjs draft-case-file <report> --json` for one case, or `npm run docs -- case-file` for every case. Confidential: for the case officer and anyone the file is lawfully shared with.

Start from the command output, never memory. Use record references in the answer. Never write a discloser's name into the database, a note or a draft.
