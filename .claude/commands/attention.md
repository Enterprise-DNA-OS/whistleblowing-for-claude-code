# Everything that needs a decision now, in priority order

Run `node scripts/speakup.mjs attention --json`. Priority 1 is compliance, unassigned reports and high-severity cases with no next step; 2 is overdue actions and steps, disclosers not updated, outcomes not told, protection not assessed and workload; 3 is quiet cases, cases past target, training and retaliation checks coming up. Present by priority with the reference. Say plainly when nothing is flagged.

Start from the command output, never memory. Use record references in the answer. Never write a discloser's name into the database, a note or a draft.
